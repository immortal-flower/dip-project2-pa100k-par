# E3：温和残差门控 SE（独立结构对照）

目标：检验中心门控分组 SE 在训练中对特征的改写过大，是否与短袖/长袖反向偏移和眼镜漏报增加有关。先前同图诊断发现：中心门控模型在 459 张图上同时漏判短袖、误判长袖；临时取消推理门控后这些错误仍存在，说明必须**重新训练**才能检验门控强度对学习轨迹的影响。结果不预设改善。

唯一改动：九组 SE 的门控由 `g=2×sigmoid(z)` 改为 `g=1+0.25×(2×sigmoid(z)−1)`，范围从 `(0,2)` 缩为 `(0.75,1.25)`。SE 内的 `512→32→512` 网络、参数量、九组分类头、ResNet18 均不变。`sigmoid` 是门控激活，不是损失函数。

控制变量：继续使用与 E0 相同的原始 train/val CSV 和图像、标签映射、256×128、训练随机水平翻转、BCEWithLogits/CE、无 pos_weight、无加权采样、15 轮、batch 64、AdamW 学习率 0.0003、weight decay 0.0005、warmup 1 轮、余弦调度、dropout 0.3、seed 42，以及按九组平均 AttrAcc 选择最佳 checkpoint。脚本在训练前逐项核对旧配置；只允许 `attention` 模式和输出目录不同。不同模型的“最佳 epoch”可以自然不同，但预设训练轮数与选择规则一致。

输出目录：`runs/E2_se_group_residual025`，不会覆盖 E0 或先前的 E2。训练后统一评价 E0、共享 SE、标准九组 SE、中心化九组 SE、新版温和门控 SE 五个 checkpoint 的 26 属性 mA、Precision、Recall、F1、TP/FP/FN/TN；并核对原先的 459 张衣袖同图错误和 347 次眼镜新增漏报是否恢复。逐图分数和案例 CSV 随结果打包。

判读：先看是否减少目标漏报/误报，再看眼镜、两种袖长、三种包的 F1/mA 和总体 macro mA/F1；不能只挑成功案例。若局部指标改善但其他属性显著退步，也要如实记录。对验证集提出的结构假设，最终仍应使用保留测试集验证；不能用本次验证集的局部变化宣称普遍提升。

本实验仍属于 B 的网络结构工作。若以后试 26 属性各有一套 SE，必须另开实验、固定本次门控选择，不与这一轮合并。
