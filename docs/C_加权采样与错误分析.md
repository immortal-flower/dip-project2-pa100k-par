# C 部分：加权采样、错误分析与 Demo

## 1. 研究问题

PA-100K 的属性分布高度不均衡。训练集中 `lower_stripe`、`boots`、`holding` 的正例率分别只有 0.50%、0.62% 和 0.96%。普通随机打乱时，一个 batch 很可能完全不包含这些属性的正例，模型因此倾向于预测负类，并获得看似很高的普通准确率。

本部分研究的问题是：**在不改变模型、损失函数和数据增强的条件下，提高稀有正例的采样概率，能否改善少数属性的 Recall、mA 和 F1？**

## 2. 方法

训练集属性 `j` 的正例率记为 `p_j`，其稀有度定义为：

```text
r_j = clamp(((1 - p_j) / p_j) ^ 0.5, 1, M)
```

其中 `M` 是最大属性权重。图片 `i` 可能同时具有多个正属性，因此图片权重取所有正属性稀有度的最大值：

```text
w_i = max(r_j for every positive attribute j in image i)
```

最后将所有 `w_i` 归一化到均值 1，并使用有放回的 `WeightedRandomSampler` 抽取 80,000 个样本。取最大值而不是求和，可以避免多标签图片因权重叠加而被极端重复；权重上限进一步限制过采样。

本文设置两个采样强度：

- E3：`M=10`，强调极端稀有属性。
- E3b：`M=5`，降低过采样强度，作为消融实验。

## 3. 控制变量

E0、E3、E3b 均使用 ResNet18、9 个分组分类头、原始损失函数、相同的数据增强与优化器。训练配置统一为 15 epoch、batch size 64、seed 42、学习率 `3e-4`。E3/E3b 唯一改变的是训练集采样器；验证集始终按原始分布顺序读取。

## 4. 采样分布

| 项目 | E3（上限 10） | E3b（上限 5） |
| --- | ---: | ---: |
| 每轮覆盖的不同图片 | 47,804 | 49,081 |
| 每轮未被抽到的图片 | 32,196 | 30,919 |
| 单张图片最大重复次数 | 10 | 9 |
| 归一化后的最大图片权重 | 3.156 | 1.693 |

![E3 采样前后属性分布](../experiments/E3/sampling_distribution.png)

E3 将 `lower_stripe`、`boots`、`holding` 的单轮出现率分别从 0.50%、0.62%、0.96% 提高到 1.66%、2.00%、3.03%。E3b 对应为 0.87%、1.05%、1.62%，覆盖图片更多，但极端稀有正例的增强幅度较小。

## 5. 实验结果

| 指标 | E0 | E3 | E3b |
| --- | ---: | ---: | ---: |
| 九组平均 AttrAcc | **92.3602%** | 92.2417% | 92.3241% |
| 宏 mA | 76.9107% | 76.5489% | **76.9361%** |
| 实例级 Precision | 85.9552% | 85.4584% | **86.0191%** |
| 实例级 Recall | **82.3774%** | 82.0200% | 81.7634% |
| 实例级 F1 | **83.7057%** | 83.2842% | 83.4087% |

普通 AttrAcc 的变化较小，但稀有属性的正例指标呈现明显差异：

| 属性 | E0 Recall / F1 | E3 Recall / F1 | E3b Recall / F1 |
| --- | ---: | ---: | ---: |
| age_lt18 | 63.48% / 73.93% | 56.48% / 69.75% | **69.99% / 80.00%** |
| upper_splice | 62.30% / 65.83% | 63.49% / 66.12% | **69.05% / 69.60%** |
| lower_stripe | **19.05% / 25.81%** | 14.29% / 17.65% | 9.52% / 16.00% |
| long_coat | 43.57% / 54.75% | 49.62% / 60.29% | **63.69% / 64.37%** |
| boots | 6.67% / 10.71% | **6.67% / 11.76%** | 2.22% / 4.00% |
| holding | 3.49% / 6.52% | **5.81% / 10.31%** | 2.33% / 4.35% |

相对官方 E0，E3 小幅改善 `upper_splice`、`long_coat`、`boots` 和 `holding`，但 `age_lt18` 与 `lower_stripe` 退化；E3b 明显改善 `age_lt18`、`upper_splice` 和 `long_coat`，却进一步降低 `lower_stripe`、`boots` 和 `holding`。降低采样上限并没有同时改善所有属性，说明属性稀有度并不能单独决定合适的采样强度。

## 6. 错误案例

![E0 与 E3 的成功及失败案例](../experiments/E3/e0_e3_error_cases.png)

成功案例表明，加权采样能够帮助模型识别尺寸很小、遮挡严重或与相邻服装连成一片的属性。例如，E3 修正了黑色长裤与靴子边界不清导致的 `boots` 漏检，也修正了手持物体和长外套的漏检。但这些单图案例不能替代总体混淆计数；官方 E0 在 `lower_stripe` 上的总体 F1 实际高于 E3。

失败案例主要是过采样带来的假阳性。黑色裤袜、普通鞋和阴影可能形成类似长靴的连续深色区域，使 E3 将非靴子样本误判为 `boots`。E3b 中也出现了 `holding` 假阳性，说明只降低权重上限不能完全解决视觉混淆问题。

## 8. 结论与局限

加权采样确实能提高稀有正例在训练过程中的可见性，但会减少每轮覆盖的不同图片，并可能增加假阳性。E3 对 `boots`、`holding` 有小幅收益，E3b 对 `age_lt18`、`upper_splice`、`long_coat` 更有效；两者都没有稳定改善所有稀有属性，也均未全面超过 E0。

五模型统一复评显示，E0 的九组 AttrAcc、宏 F1 和实例 F1最高，应作为最终总体模型。若任务强调宏 mA 与 Recall，A 的 `pos_weight` 方案收益更明确，但代价是大量假阳性；Focal Loss 对 `boots` 最有效。加权采样的价值主要是揭示采样强度和属性之间的差异，而不是替代 E0。后续可研究按属性组设计权重，避免年龄、服装、携带物等不同性质的属性共用同一强度。
