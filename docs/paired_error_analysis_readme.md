# E0 与 SE：逐图成对错误分析

运行 `scripts/run_paired_error_analysis.sh` 不会训练新模型。它使用相同的 PA-100K `val.csv`、`dataset.py` 标签映射和确定性验证预处理，按图片文件名对齐 E0、九组 SE 和中心门控九组 SE 的预测。服务器若保留 `runs/E0_baseline/e0_val_predictions.pt`，会直接复用；否则由 E0 checkpoint 补算。

程序对三模型全部 26 个属性的 TP/FP/FN/TN 与已保存的统一指标文件逐项核对，任何不一致都报错，不生成误导性结论。重点分析眼镜、短袖、长袖、背包、单肩包和手提包六个二值属性；概率阈值仍为 0.5，损失函数和训练结果不变。

输出目录为 `runs/E0_E2_paired_errors`：

- `paired_report.md`：每属性新增误报/漏报、修正误报/漏报和三模型 F1。
- `paired_predictions.jsonl`：六属性的全部 60,000 条逐图记录，包括图片名、真实标签、三模型预测及概率。
- `case_changes.jsonl`：E0 与新版 E2 判断发生变化的记录。
- `paired_summary.json`：机器可读统计与九组 SE 在新版错误图上的表现。
- `case_gallery.html`、`images/`、`selected_cases.jsonl`：每属性每类变化最多 8 个代表性图片，混合抽取临界、高置信度和随机样本，可离线打开 HTML 人工观察。
- 画廊中的衣袖图片同时显示短袖和长袖分数；包的图片同时显示三种包的分数，便于观察相互误判。
- 三个 `*_val_predictions.pt`：全部 26 属性的逐图预测，用于后续复查。

新增错误的定义是 E0 正确而新版 E2 错误；修正错误则相反。图片案例是定性材料，不代表总体比例。尤其不能仅从预测差异推断 SE 门控就是错误的原因，仍需人工看图片、检查预测概率与模型权重。验证集已用于模型选择及多次结构尝试，最终改进结论需要未参与设计的测试集确认。
