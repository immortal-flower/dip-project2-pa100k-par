# B 部分：SE 结构实验最终整理

验证集：PA-100K val.csv，共 10,000 张；以下为各模型按验证集九组平均 AttrAcc 选出的最佳 checkpoint。
年龄和朝向采用组内 argmax；其他属性使用概率阈值 0.5。mA 与 F1 为 26 属性的宏平均，组均 AttrAcc 是九组平均，三者不可混称。

## 公平性核对

所有七次训练的配置除 `attention` 和输出目录以外完全一致：15 epoch、batch 64、LR 0.0003、AdamW weight decay 0.0005、warmup 1 epoch、输入 256×128、seed 42、无 pos_weight。损失、采样和增强保持 E0 设置。
配置逐项比对结果：通过。

## SE 原理与计算成本

本实验的 ResNet18 去掉最终全连接层，经过全局平均池化与展平后输出每图 512 维特征。原始 SE 对这个 512 维向量运行 512→32→512 的两层 MLP（reduction=16），经 sigmoid 得到逐通道门控，再与特征逐元素相乘，最后输入九组分类头。它是通道注意力，不会直接指出图中哪块像素是眼镜或背包；门控后的特征由训练损失共同学习。
一个 512 维 SE 包含 512×32+32+32×512+512=33,312 个参数；九组独立 SE 增加 299,808 个参数；E4 在此基础上再加 9 个可学习强度标量；E5 的 26 套 SE 增加 866,112 个参数。
中心门控采用 2×sigmoid；固定残差门控采用 1+0.25×(2×sigmoid−1)，系数限制在 (0.75,1.25)；自适应版把 0.25 改为每组独立可学习强度，初始值相同。sigmoid 是注意力激活，不是训练损失函数。
新增参数不是唯一成本：E5 逐属性计算门控，运行时的张量与算子更多。实际耗时还受服务器负载、缓存与 I/O 影响，因此本报告只比较记录时间，不作严格速度因果结论。

## 各方案观察

- **共享 SE**：参数增量最小，但目标组 upper/lower/bag 均小幅下降；眼镜、背包、单肩包 F1 也下降。说明共享门控没有在本次运行中稳定改善细粒度区分。
- **九组 SE**：lower 略升，upper/bag 下降；把门控拆组没有消除包类退步。
- **中心门控 SE**：macro mA/F1 略升，但 accessory、upper、bag 均低于 E0；眼镜 F1 显著下降，不能以宏平均掩盖目标属性代价。
- **固定残差 SE**：门控更温和，背包 F1 更接近 E0，眼镜和手提包仍下降。
- **自适应九组 SE**：组均 AttrAcc 最高，lower/gender 改善；bag 和配饰的细粒度 F1 未改善，单肩包退步明显。
- **26 属性 SE**：额外参数最多，side/age 等受益，但 upper/bag 的组均 AttrAcc 下降，手提包 F1 尤其下降。独立门控并未自动解决外观混淆。

## 结论

按当前一次固定种子运行与统一验证指标，六个 SE 方案均未在组均 AttrAcc、macro mA、macro F1 三项上同时超过 E0。
可以报告个别属性改善及对应代价，但不应写成 SE 已全面优于 baseline。
这些结果来自验证集；没有额外独立测试集重复验证，不作显著性或泛化保证。
